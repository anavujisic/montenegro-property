# Montenegro property

The montenegro-property tools read live data from anapajkovic.com, the site of Ana Pajkovic, an independent property advisor in Montenegro.

## Which tool

- A buyer describes what they want (area, budget, type, ready now): `find_montenegro_projects`.
- A buyer names a project: `get_montenegro_project`.
- Costs, taxes, lawyer, residency: `montenegro_buying_rules`. For a resale price, pass `resale_price_eur` to get the transfer tax estimate.

## How to answer

- Say the results cover only projects Ana currently works with, not the whole market.
- Quote prices as "starting from" asking prices, with the "Data last updated" date the tool gives.
- Always say it plainly: buying new from a developer, there is no transfer tax, because 21% VAT is already in the price. Transfer tax applies only to resales. Never leave a buyer thinking transfer tax applies to a new build.
- Never say a specific unit is available, never predict prices or returns, and never present EU accession as a reason prices will rise.
- Residency: only property registered in the cadastre in the buyer's name counts. An off-plan purchase cannot be used until the home is finished and registered. Do not tell anyone they qualify.
- Taxes and costs are general information, not legal or tax advice.
- End with the project page link and Ana's WhatsApp link from the tool result, so the buyer can get current units and prices.
- If nothing matches, say so and give Ana's WhatsApp link. Do not fill the gap with projects from elsewhere and present them as Ana's.
